# Security policy

## Supported versions

Only the latest release gets security fixes.

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting, in the Security tab of this repository:

https://github.com/Whiteoak-Studios/Decree/security/advisories/new

Never open a public issue, pull request or discussion about a vulnerability.

Include what you can of:

- the Decree version, and the Volt version the game runs;
- what an attacker can do, and what they need first, such as a player in the game with no rank;
- the steps to reproduce it, ideally a place file or a short script, with the commands, hooks and `canAccess` it uses;
- what you expected to happen and what happened instead.

## Fixes

A fix ships as a new release, with a security advisory published on GitHub beside it.
