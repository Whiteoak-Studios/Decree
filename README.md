# Decree

Decree is Whiteoak Studios' fork of [Cmdr](https://github.com/evaera/Cmdr), the admin command console for Roblox, published publicly on Wally as `fadeluc-123/decree`. Whiteoak maintains it, with its networking moved onto Volt and an improved developer command interface. Frontier Zero is its first consumer.
